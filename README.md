# NOCa (Newtonian Orbital Calculator)

NOCa is a python librairy with the goal of computing spacecraft related problems in a one body problem, such as :
- Position and speed vectors with respect to time (done)
- Maneuver based on the impulse vector that affects a spacecraft orbit (done)
- Basic Maneuver such as eccentricity change, inclination change...
- Rendez-vous planning with relative speed and pre made processes
- Visualization of orbits on the body
- Satellite constellation planning

## External Credits

- [fast-kepler](https://pypi.org/project/fast-kepler/), for solving the kepler equation
